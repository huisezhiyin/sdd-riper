# 归档文章

这里放的是 SDD-RIPER / Harness 方法论形成过程中的旧文章和素材稿。

它们没有被删除，是因为里面仍然有不少可复用表达、例子和历史思考；但它们不再是一线阅读入口。新读者请优先从上一级的 [文档阅读地图](../README.md) 开始。

## 为什么归档

- 多篇文章解释同一个核心变化：程序员从代码执行者转向目标、边界、验收和沉淀的维护者。
- 旧文章里有更重的 SDD / 阶段论表达，容易和当前 `sdd-riper-one-light` 的轻量 Harness 主线混在一起。
- 当前项目更强调最小混沌单元、水流理论、checkpoint、最小 spec 与按需回读。

## 使用方式

- 写新文章时，可以从这里摘取例子和表达。
- 做团队分享时，只选和听众相关的片段，不建议整篇串读。
- 如果某篇文章被重新整理成当前主线，请把归档版本继续留在这里，避免历史链接和素材丢失。
