## 超级个体

不知道从什么时候开始流行“超级个体”这个词，还没等我跟上时代，它就已经泛滥得像是深春的柳絮了：不仅到处都是，而且还会让我过敏。平时和一些小伙伴闲聊的时候，大家总会用“超级个体”互相打趣，仿佛自己被别人说是个超级个体是一件非常丢人的事。究其原因，其实还是“超级个体”这个 Title 太唐突，定义太失真，位置也太尴尬。

现在比较流行的一种定义，是把“超级个体”与 OPC（One Person Company，一人公司）联系起来：一个人借助 AI 成为一支小型队伍。

但是，我经常谈论的，以及我所认为的超级个体，往往比这个定义更宽一些。通常是说这个人很强、很厉害，可以高效地产出高价值的产物，并不一定要和“一人公司”绑定。以前我们通常会用“天才”来称呼这些人，而超级个体更像是一个“被 AI 赋能的新称呼”。这一点屡见不鲜：LLM 到来之后，大量的业务、产品和岗位都被“AI 赋能”换了个名字，但实际上东西还是那堆东西，只是听起来更赛博了。

## 《乡村教师》

我在初中的时候开始看科幻作品，当然不可避免地会接触到大刘。而我对他印象最深的并非《三体》，而是《乡村教师》。当时我被其中的设定所震撼：人类作为一种智慧种族，无法像外星人一样，以类似基因传承的方式把知识直接给予后代，只能通过教师、书籍、材料来让新的人类学习旧的知识。虽然人类也在数万年的进程中不断尝试压缩（compact）知识，以提高这一行为的效率，但是随着科技进步和各个专业领域的不断发展，需要学习的前置信息仍然越来越多。十来年前，程序员面试可能只需要写一个 Hello World，现在却需要了解基础设施知识、设计模式、LLM 的原理和使用等一大堆东西。

有的时候我认为，这种面试难度的陡升，并不仅仅是一种内卷，而是领域和专业在不断前进的过程中必然出现的情况：以前你从珠峰山脚下开始爬，只需要具备攀登海拔 3000 米的水平；现在你到了半山腰，如果想继续前进，就至少要有攀登 6000 米的水平。Benjamin F. Jones 在 [_The Burden of Knowledge and the “Death of the Renaissance Man”: Is Innovation Getting Harder?_](https://www.nber.org/papers/w11360) 中，将这种随着知识积累而不断增加的学习负担称为 Burden of Knowledge（知识负担）；而我更愿意把它叫作“海拔堆积”：随着海拔不断提升，所有的在任者都必须不断自我提升，拥有对应的能力才能留在赛道上；所有的继任者则必须先积累对应的海拔，才能加入赛道。

所以我们会发现，人类如果想钻研一个方向的顶尖内容，就必须学习、了解、消化这个方向的所有基础知识，顶尖研究往往至少要从博士阶段开始。而如果不幸在一开始进错了赛道，后来想要转向，就可能付出极其昂贵的重新攀登成本（为 β 淀粉样蛋白（Aβ）研究方向的科研人员默哀）。

尽管一些“夏尔巴人”拥有更强的天赋，可以压缩这方面的沉淀和积累，更早地出发和探索，但是最基本的原理没有变化。在最极限的时候，甚至可能出现这样一种情况：抵达某个领域前沿所需的不可压缩知识，开始逼近一个人终其一生能够掌握的极限。

就好比疯狂健身甚至打兽药，最多只能让你硬拉 500 kg 和脑袋变尖，但是无法让你成为正义的奥特曼，去杀死红井里的小怪兽。

## Central Finite Curve

我那时候年纪还不大，对于“人类有限”这点感到很悲伤，就好像是 R&M 里被困在中央有限曲线中的芸芸庸才一样，只能悲伤地接受人类这个命运共同体（而且这个命运共同体还在不断内讧和互相倾轧）有一天会走到黄昏的尽头，温和地走进那个良夜。

所谓 **Central Finite Curve（中央有限曲线）**，在 R&M 这部作品里，是 Rick 们从无限多元宇宙中人为划出的一个范围：它将 Rick 始终处于智力顶端的那些宇宙与其余世界隔离开来，曲线内的一切都是受控的、有上限的。而人类本身也受制于类似的机械降神机制，被管束在肉体的“中央有限曲线”内。在过往相当一部分科幻作品中，尤其是赛博朋克类作品，如果要解决这个问题，方法大多是“血肉苦弱，机械飞升”：使用外挂大脑和机械义体来突破人类的极限，让人类成为 **NewType**。不过从现实角度出发，如果不发展个百十来年，这件事都和豆包的幻觉一样扯淡，无法达成。

不过，ChatGPT 的横空出世，提供了一种别样的“暗度陈仓”的可能性：把 LLM 作为一种外挂大脑，从而辅助人类突破中央有限曲线，获得更多可能。人类并不是一定要在自己脸上安八个电子眼，或者在脑子里装一台充盈着冷却液的小型量子计算机，才能完成这一愿景。所以，与其说我当时被 LLM 的原理和表现震惊得瘫坐在椅子上，不如说我是被“突破人类肉身智力上限”这种核弹般的可能性彻底震撼了。

一转眼过去好几年，随着 LLM 的强化、升级，越来越多的人用它取代搜索和百科（为百度默哀），询问它各种问题和 Bug（为 Stack Overflow 默哀），用它来写代码（为 2025 年和 2026 年选择了普通软件工程专业的大学生默哀）。它逐渐成为社会生活中的基础设施，也越发清晰地朝着这一方向狂奔：人类可以选择从半山腰而不是从山脚出发，从而更高效地在更高层次上探索和研究。人类也开始从一个微妙的角度溶解中央有限曲线的鳞片，而不是只能被它冷酷地镇压在五指山底。

## 爱因斯坦只有一个

超级个体是一种天赋，我觉得承认这件事比否认这件事更合适。爱因斯坦来到这个年代仍然会有突破性的发现，而且只会比以前的发现更惊人、更顶级；但 80 亿现代人却无法批量成为爱因斯坦，这就是超级个体的真实写照。一个超级个体，应该是一个拥有强抽象、建模、泛化、判断、验证和问题收束能力的人。他能够借助大模型调用被封装的专业知识，从不同领域的半山腰切入，把多个专业转化成可以统一建模、调用和验证的问题，并对一个有边界的端到端结果负责。

汽车作为人类史上最伟大的发明之一，极大地提升了每个人工作和生活的范围，拓展了城市的边界，改变了人类的生活方式。每个人都能学车、买车、开车，但是有人可以把车开进拉力赛和 F1 的赛场，有人则考五次也过不了科目二。我非常相信 LLM 就是下一辆汽车，可以改变人类的工作和生活方式，极大地提升人类的能力边界；但是我同样相信，有些人会借助 LLM 成为 F1 冠军，有些人则无法通过侧方停车。这既有天赋的问题，也有学习的问题。就像在赛博朋克的世界里，人人都能装义体，但是有人能成为天上地下战斗力第一人亚当重锤，有人则只能成为被亚当一拳打爆的丽贝卡。给八十亿人接入大模型，虽然能提高八十亿人的生产效率，但是不会产生八十亿个超级个体，所以超级个体会和以前的天才一样依然稀缺。

一个强大的超级个体，可以借助 LLM 和 Agent，同时并行推进多个领域、多个方向上的多件事，并且使用自己的泛化建模能力，让这些问题在他和 LLM 的思维里都成为类似或者接近的模型，从而降低人类上下文切换的成本，并使 Agent/LLM 更高效地解决问题和沉淀技巧。一个超级个体完全可以取代一个甚至多个小规模团队，并且更高效地产出更多结果：毕竟人和 LLM 的通信成本，可比几十个人互相通信低太多了。

## 超级个体人 3

超级个体是一种天赋，但超级个体的 Level 并不是抽卡游戏：不是出生的时候抽到一张 SSR，这辈子就永远是 SSR。它更像《龙珠》的内核：**天赋 + 漫长修炼 = 最终抵达的地方。**

悟空有赛亚人的底子，又有近乎无穷无尽的修炼欲望，经过漫长的修行最终点燃超级赛亚人 3；悟饭的潜力甚至比悟空更加夸张，但他并不愿意把“不断变强”当作人生唯一的主轴，所以在很长一段时间里，反而不断被那些持续修炼的人追上；至于天津饭，他已经是最勤奋的武道家之一，也能通过日复一日的修炼站到地球武道家的顶端，但再怎么修炼，也无法凭空把自己练成超级赛亚人——不仅仅是因为他没有成为“超级个体人”的天赋，还因为他用不到 LLM。

达到“超级个体人 3”级别的人，不仅可以在很短的时间里看懂一个极其复杂的问题，还拥有极强的主观能动性，会主动发现问题、创造目标、寻找资源，然后把一件原本没人负责的事情推起来。他们更像一颗真正点燃的恒星，不仅自己持续产生巨大的能量，还会通过引力把周围的人、资源和问题拖进自己的轨道，再把能量不断向外辐射，cover 住整个太阳系。运气足够好的时候，这个系统里甚至会慢慢长出一颗“地球”——一个宇宙中绝无仅有的智慧星球。而“超级个体人 2”则更像一颗褐矮星。他们同样拥有巨大的质量，也可以自己发光发热，但可能缺少一部分行动力，或者只愿意停留在自己的舒适区里，因此很少主动把遥远的问题拉进自己的轨道。他们依然可以很好地解决落到自己面前的问题，只是缺乏动力主动创造一个太阳系。

所以，对于“超级个体人 3” 来说，天赋、主观能动性、好奇心与求知欲，以及旺盛到足以长期燃烧的精力，几乎缺一不可。

## 用超算集群玩扫雷

我在 2025 年 4 月的时候组装了一台电脑，CPU 是 9950X3D，显卡是 5080，64 GB 内存，4 TB 硬盘。那时候还在硬件价格起飞的前夜，所以我上了一套顶级配置。但是组装好之后，除了一阵子拿它来跑过一些模型，剩下的大部分时间，我都是用这套性能怪兽来看视频和直播。

现在很多公司和团队对超级个体的使用，也和我的行为非常相似：给超级个体指派一些简单或者局限性很强的任务，让他们不断重复这些工作。这就好像无论我是用自己的性能怪兽看一场直播，还是同时看一百场直播，都一样毫无价值。因为我明明可以用这台电脑跑模型、写代码、玩游戏、和 LLM 谈天、处理照片、编辑视频……一台性能强大的电脑，在我手里可以做几百件事，从各种角度给我带来真实的收益。那么，只让超级个体做什么后端、什么全栈，就和使用性能怪兽同时看 100 场直播一样愚蠢。就算把一个超级个体放到超级程序员的位置上，也只是相当于把老虎从笼子里放到了动物园，它依然无法发挥本来的实力：在零下 20 摄氏度的大兴安岭巡视上百平方公里的领地。

而这种问题的来源，和组织的 AI Native 转型困难是一个道理：过去这一整套团队运行机制，都是在 LLM 出现之前设计、形成的。在 LLM 出现之后，试图用这套机制去适应 LLM 时代的东西，当然是完全不可行的。现代人类和公司在传统专业细分理念的指导下，天然会让某个人去做某件比较细分的事情，然后通过大规模协作来达成某个更大的目标。但是 LLM 和超级个体出现后，超级个体一个人就可以跨领域，更高效地产出更高价值的结果。此时把他放到笼子里，那和租超算集群玩一个月扫雷有什么区别？

## NewType 就要开高达

既然传统岗位无法完整描述超级个体，那么最容易想到的做法就是：再创造一个“超级个体岗位”。但如果我们只是给他换一个 Title，根本问题仍然没有解决。

在高达的世界观里，只有 NewType 才能发挥高达的最大价值，所以“**强大的 NewType 驾驶员 = 顶尖高达的宿主**”就变成了高达的主线公式。回到现实世界，我们也不应该再尝试把某些已经细分的事情回笼给这个岗位，而应该取消对这个岗位的限制，让超级个体有权限、有机制去自由地开发、创新，端到端地负责并解决问题，最大限度地提升效率、创造价值。一个新的时代、一些新的事物，就必须由新的人使用新的法则和新的方式，来创造全新的世界。

超级个体真正需要的不是一个更高级的 Title，而是一种新的组织运行机制。

传统组织的基本方式是：

> 先定义岗位，把人固定在岗位里，再让问题在岗位之间流转。

适合超级个体的方式应该反过来：

> 先识别一个人能够控制多大的问题空间，再让他流向真正重要的问题，并围绕问题临时取得必要的上下文、资源、权限和结果所有权。

普通员工可以围绕岗位配置，深度专家可以围绕专业配置，超级个体则应该围绕 Problem Space 配置。

> **不再是定一个岗位然后招一个合适的人，而是招一个超级个体并围绕他设计岗位。**

我当然不是一个纯粹信奉英雄叙事的人。只是从理性的角度来说，我在多 Agent 协作时，也会考虑使用 fable5 去做架构设计，然后使用 qwen3.8 去做代码执行，这是一种合理的位置分配和能力边界定位。

当你的目标只是配一台电脑打一打英雄联盟，那你自然会从图吧抄一套极致性价比且尽量不会爆炸的配置，因为这个行为是从收束之后的窄目标出发的。但是如果你先配了一台高达四万元的超级性能怪兽，那你就不应该只用它玩腾讯游戏，或者只用它看直播。你应该把它定位成自己的工作站、生产力工具和全能游戏机，疯狂地在各个维度榨干它的所有性能。超级个体亦是如此。一个组织离不开三千台只能打开 Office、浏览网页、使用 IM 的办公电脑；一个组织也绝对不能把一台二十万的极致工作站拿去放电影。

## 个体超级

我在前司的时候，大家最喜欢谈论、也最喜欢拿来调侃的一句话，就是“逃逸平庸的重力”。现在想想，这句话真是充满了不食人间烟火的味道。为什么？因为几乎所有人都只是普通人，这是这个世界的本质，也是它能够运转的基础。人类本来就是一种大而同、小而异的生命，为什么偏要把这个世界里的绝大多数人评价为“平庸”呢？

普通并不是错，也不需要被逃逸，更不是什么向下拖拽别人的重力。正是海量平凡的人类组成了今天的社会。那些认为普通人是“平庸的重力”的人，大可以自己去“火星”生活，不用和我们挤在一起。

普通人当然也不应该被留在 LLM 时代之外。LLM 和 Agent 从来不是超级个体的专属武器。超级个体可以借助它们跨越专业边界、控制更大的问题空间，普通人也可以用它们减少机械劳动，进入一两个相邻领域，独立完成一些过去必须依赖别人的事情。它未必会把每个人变成天才，却可以让一个普通人成为比过去更完整、更自由的个体。

当然，正确的废话总是会让人觉得厌烦，所以我们的产品也不能只停留在嗡嗡作响的广告里，而是正在顺着这个方向大踏步地前进：钉钉开始变得更加 AI 亲和，千问办公、悟空和 DWS 都在尝试降低普通人使用 Agent 的门槛。

虽然这的的确确是一个广告，但是对于那些不想研究 Agent 架构，也不想掺和进 LLM 无底深渊的人，[千问办公](https://qwenwork.cn/docs/product-introduction)可能是一条最简单的路径。它试图让一个人只用一句话，就能完成数据分析、制作 PPT、剪辑视频和搭建网页等原本分散在不同软件与专业里的工作。普通人不需要先成为数据分析师、设计师、导演和前端工程师，才有资格开始解决手里的具体问题。

而 [DWS](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli) 则更适合有一些探索欲、又熟悉 Agent 的程序员。至少就我所知，已经有好几百个“赛亚人”用 DWS 写了自己的个人钉钉——包括我自己。我以前已经花了一整篇文章教大家怎么使用 DWS，也认真地总结了一些案例给大家参考。当然，人与人之间的差异不会因为工具的出现而消失，但每个人可以触及的能力边界，都比过去稍微远了一点。我们也正在绞尽脑汁地设计、开发，希望能帮助大家在 LLM 时代完成个体的超级。

## 杂谈

写这篇文章的时候，我特别躁动。可能是因为杭州的天气，也可能是因为觉得自己正在不可逆地沉入一片巨大而又平静的湖泽。

一方面我总是反复强调，自己很早就开始使用 LLM、开始做和 LLM 有关的事情；可另一方面，我又觉得自己根本没有摸透 LLM 的过去、现在和将来。我脑子里所有关于它的知识，就像放置了二三十年、已经失色的幻灯片。它们一张张闪过、串联起来时，似乎可以组成完整的画面；可当它们叠摞在一起时，我又觉得这些东西并不属于我。

我相信很多人身处这个时代，都会和我一样，甚至比我更加迷茫。

这篇文章最初其实是一篇软文。我最近一直在推广 DWS，相信认识我的人也都知道这件事。我从小就特别执拗，写命题作文的时候也总是会把头扭过去，死活不愿意大大方方地把“我正在完成任务”这件事放进自己的文章里。或许这也是我最大的缺点之一，不然我早就像酥神一样拿到大结果，美美百万撤离了。

但是，我也确实很想谈谈所谓的 AI Native，以及所谓的超级个体。这篇文章并非由命题作文所催生。

互联网和大模型带给每个人的东西，到底是好是坏？还是说，既有好，也有坏？每次面对这个斯芬克斯谜题，我都好似被丢弃在 Boötes Void 的中心，发不出任何声音，只能听到轰鸣的寂静。

只是，大风吹倒梧桐树，自有旁人论短长。或许十年、二十年之后，人类会给出公正的评价。但从我个人的 opinion 来说，互联网、LLM，或者一部分科技，或许正在把人类变成大规模集中式养殖体系下的白羽鸡。

我们被束缚、被填满，又从一个拥挤的地方被运输到另一个拥挤的地方。地铁和汽车运输着我们的身体，电脑和手机承载着我们的灵魂。互联网和大模型像不断喷进发动机的一氧化二氮，催动着世界，也催动着我们踉踉跄跄地越跑越快。

我必须像一台 OK-550 铅铋合金冷却快中子反应堆一样，咆哮着维持运转。因为一旦停下，凝固的金属冷却剂就会堵塞所有管路，让整套系统彻底死机。

那是不是这个世界运转得太快了？

又或者，是我运转得太快了？

就好像 R&M 里王医生所说的，修理、维护和清洁从来都不是什么伟大的冒险，它们就只是工作而已。我们需要吃饭、睡觉、喝水，需要日复一日地维护自己；这些简单、普通，甚至有些无聊的事情，才占据了生命中的绝大部分。即使是世界上最聪明的人，也要面对这些事情，宏伟的目标和有趣的故事从来都不是一切的主轴。

但是刷着抖音、焦虑焦躁的腌黄瓜们；但是被 LLM FOMO 折磨的办公楼沙丁鱼们；但是挤在斑马线前、还在钉钉里回复消息的电子牛马们；但是那几个悬而未决的 CLI 需求怎么办；但是 Agent 战场上步步紧逼的竞争对手要戳我的腿肚子了；但是 AI Native 的 OKR 到底能完成吗；但是我的 Code Agent 各项 Benchmark 都不及格；但是 Codex 的额度怎么还不重置啊；但是我已经开了七八个 LLM 相关的会员了；但是我妈又在催我结婚了；但是我现在流了好多汗而且还饿着肚子；但是我睁眼是大模型，闭眼还是大模型，连焦虑都像是大模型帮我分泌出来的……但是我还有好多但是。

不，明明没有什么但是，去他妈的 LLM 吧，杭州好吵。

八月八日，无雨。
